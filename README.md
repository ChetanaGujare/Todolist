# 📋 Todo List - Task Manager

A simple, interactive **Todo List** application built with vanilla JavaScript, HTML, and CSS.  
This project helps you track your learning tasks with **localStorage persistence** — your tasks stay saved even after you refresh the page.

 🚀 Features

- ✅ Add new tasks
- ✅ Mark tasks as complete / incomplete
- ✅ Delete individual tasks
- ✅ Clear all tasks (with confirmation)
- ✅ Filter tasks: **Today** (all), **Upcoming** (pending), **Done** (completed)
- ✅ Real-time progress tracking (total, completed, percentage)
- ✅ "Today's Focus" banner showing remaining tasks
- ✅ Data persists using browser's **localStorage**
- ✅ Fully responsive — works on mobile, tablet, desktop

 🛠️ Technologies Used

- HTML5
- CSS3 (with Flexbox & custom properties)
- Vanilla JavaScript (ES6)
- Font Awesome (for icons)
- localStorage (for data persistence)
