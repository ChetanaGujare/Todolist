# 📋 TaskFlow · Premium Todo List

A modern, interactive **Todo List** application built with vanilla JavaScript, HTML, and CSS.  
This project helps you track your learning tasks with **localStorage persistence** — your tasks stay saved even after you refresh the page.

## ✨ Features

- ✅ **Add new tasks** – quickly add tasks via the input field or the "New Task" button.
- ✅ **Mark tasks as complete** – click the checkbox or the task title to toggle status.
- ✅ **Delete individual tasks** – remove tasks with a single click.
- ✅ **Clear all tasks** – with confirmation to prevent accidental deletion.
- ✅ **Filter tasks** – view **All**, **Pending**, or **Done** tasks with tabbed navigation.
- ✅ **Real‑time progress tracking** – total, done, and pending counts update instantly.
- ✅ **Visual progress ring & bar** – see your completion percentage at a glance.
- ✅ **Dark / Light mode** – toggle themes with a smooth transition.
- ✅ **Glass‑morphism UI** – modern, blurred background with subtle shadows and gradients.
- ✅ **Responsive design** – works flawlessly on mobile, tablet, and desktop.
- ✅ **Data persistence** – all tasks are saved in your browser’s `localStorage`.

## 🛠️ Technologies Used

- **HTML5** – semantic markup
- **CSS3** – custom properties, Flexbox, glass‑morphism, animations
- **Vanilla JavaScript** – ES6+ (IIFE, arrow functions, template literals)
- **Font Awesome** – for icons
- **localStorage** – for data persistence

## 📦 Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/ChetanaGujare/Todolist.git
   cd Todolist
   Open the project

2.Simply open index.html in your favorite browser.

3.All styles and scripts are self‑contained – no build tools needed.

Start adding tasks

Type a task in the input field and press Enter or click the + or New Task button.

Click the checkbox or the task text to mark it as done.

Use the tabs to filter tasks.

The progress ring and stats update automatically.
